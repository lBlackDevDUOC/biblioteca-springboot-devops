# Código de conducta

## Nuestro compromiso

Este proyecto académico busca mantener un ambiente de colaboración respetuoso, seguro y profesional para todas las personas participantes.

## Comportamientos esperados

- Comunicarse con respeto y de forma constructiva.
- Aceptar observaciones sobre el código sin ataques personales.
- Ayudar a otros integrantes cuando sea posible.
- Documentar cambios y decisiones relevantes.
- Respetar el trabajo y autoría de otras personas.
- Evitar publicar información personal, contraseñas, tokens o credenciales.

## Comportamientos no aceptables

- Insultos, hostigamiento o discriminación.
- Modificar deliberadamente el trabajo de otra persona para perjudicarlo.
- Publicar credenciales o datos privados.
- Utilizar los canales de colaboración para contenido ajeno a la actividad de forma disruptiva.

## Aplicación

Las situaciones que afecten el ambiente de trabajo deben comunicarse al docente o responsable del repositorio. El objetivo es corregir el problema y mantener una colaboración adecuada durante el laboratorio.
